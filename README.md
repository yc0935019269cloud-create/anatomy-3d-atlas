# 解剖 3D 圖譜

兩套可直接開啟的互動式 3D 解剖圖譜：

- [腦與視覺路徑](brain-visual-atlas-3d/index.html)（線上分檔版；離線單檔：`腦與視覺路徑3D.html`）
- [頭顱骨](skull-atlas-3d/index.html)（線上分檔版；離線單檔：`頭顱骨3D.html`）
- [圖譜選單](index.html)

網站由 GitHub Pages 提供。首頁卡片開啟分檔版，讓瀏覽器可個別快取程式與模型資料，避免每次重新下載包含全部內容的單檔 HTML。第一次載入仍須下載並在瀏覽器解壓模型資料；後續重訪可重用快取。若要離線使用，可直接開啟專案內的單檔 HTML。返回瀏覽器上一頁可回到選單。

## 授權與來源

各圖譜的模型、程式、標示資料與第三方來源授權，請見各自目錄中的 `README.md`、`ATTRIBUTION.md`、`assets/NOTICE` 與來源清單。隨圖譜提供的講義及參考原圖由各原權利人持有；已取得發布授權。

## 維護

每個專案目錄保留可編輯來源與建置說明。`node_modules` 不納入版本控制；顱骨專案的原始 Blender 與壓縮來源備份留在本機，避免把 100 MB 以上檔案推上 GitHub。可攜式 HTML 頁面已包含網站所需模型資料。
