# 解剖 3D 圖譜

三套可直接開啟的互動式 3D 解剖圖譜：

- [腦與視覺路徑](brain-visual-atlas-3d/腦與視覺路徑3D.html)
- [頭顱骨](skull-atlas-3d/頭顱骨3D.html)
- [腦神經與顱骨孔洞（骨＋神經＋腦整合）](cranial-nerves-3d/神經與顱骨3D.html)
- [圖譜選單](index.html)

網站由 GitHub Pages 提供。點選首頁卡片即可開啟各圖譜；返回瀏覽器上一頁可回到選單。

整合圖譜把頭骨、12 對腦神經、眼窩與腦放在同一座標，可看到每條神經穿過哪個孔；說明見 `cranial-nerves-3d/README.md`。

## 授權與來源

各圖譜的模型、程式、標示資料與第三方來源授權，請見各自目錄中的 `README.md`、`ATTRIBUTION.md`、`assets/NOTICE` 與來源清單。隨圖譜提供的講義及參考原圖由各原權利人持有；已取得發布授權。

## 維護

每個專案目錄保留可編輯來源與建置說明。`node_modules` 不納入版本控制；顱骨專案的原始 Blender 與壓縮來源備份留在本機，避免把 100 MB 以上檔案推上 GitHub。可攜式 HTML 頁面已包含網站所需模型資料。

## 完整講義 PDF

兩套模型頁下方各有 PDF 入口：頭顱骨對應骨質眼窩講義；大腦對應視覺路徑講義。點擊後在新分頁開啟，保留模型頁方便對照；PDF 不會隨模型預先下載。
