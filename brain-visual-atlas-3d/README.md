# 腦與視覺路徑 3D 解剖圖譜

直接用 Chrome 或 Edge 雙擊 **腦與視覺路徑3D.html**。這是約 33.2 MB 的單檔離線版：已包含模型、程式與 13 頁講義圖片，搬移這一個 HTML 也能使用，不需要架伺服器。

## 使用

- 左鍵拖曳採畫面方向的自由旋轉，放開即停；滾輪縮放、右鍵平移；觸控裝置可用雙指操作。
- 指示線具有深色外框與亮色主線；移到名稱或選取時，對應線與端點變金色，其餘線淡化。實體維持實線、示意維持虛線。旋轉過程標籤位置固定，不會跳邊。
- 右上角「隱藏所有名稱／顯示所有名稱」同步處理模型標籤、側欄名稱、路徑文字和構造說明，隱藏時保留編號。
- 六個主題：視覺路徑 10 項、腦底血管 12 項、血管分支 18 項、近反射 17 項、腦內側面 13 項、深部構造 21 項。總共 70 個不重複學習項目；項目可以跨主題。
- 搜尋支援中文、英文與講義編號。點選標籤／側欄可高亮構造並查看說明及對應 PDF 頁碼。
- 「腦外層」調透明度；「右半腦」可移除右側配對網格以看左腦內面；「示意路徑」切換補充的示意幾何。
- 「13 頁原圖對照」可逐頁查閱原講義。「講義重點」是另行整理的解說，並非講義原附答案。名稱隱藏時這兩個入口不顯示答案。
- 手機畫面模型較小，可放大；大量構造建議用電腦或平板橫向觀看。

## 內容範圍與精度

依使用者提供的 `2.視覺路徑+標號-02.pdf`（13 頁）整理。涵蓋講義具名的視覺路徑、腦循環及分支、近反射構造、距狀溝／頂枕溝、Gennari 線、腦下垂體、蝶鞍與內囊相關構造，另加清楚標示的必要背景構造。

原始模型來自 Z-Anatomy，以既有 Blender 檔擷取 244 個網格、570,762 個頂點；無另行簡化面數。模型包含皮質、腦幹、深部核團、眼、神經、血管和蝶骨。原始作者與授權見 ATTRIBUTION.md。

- **原模型構造**：已有獨立網格。標點是依代表位置吸附至原網格的點，未經逐點專業定位核驗。
- **區域導引**：以鄰近解剖表面提示範圍，不表示精確功能區邊界。
- **示意模型**：原網格缺少的視放射、Meyer’s loop、Baum’s loop、內囊分段、部分微小動脈、睫狀肌與瞳孔括約肌等另以線束或環形示意；不是個人 MRI 纖維追蹤或血管影像。
- **原圖／層次構造**：Gennari 線在皮質內層次，3D 只有 V1 區域提示，請看第 12 頁照片。

標記指線可穿透表面；旋轉時請注意前後。成對構造主要標左側。第 8／10 頁圖中第 6 號未具名，因此保留未判定；動眼神經核／EW 核作獨立補充。第 12／13 頁標本數字 1–18 沒有完整答案表，保留原頁，不自行填上確定答案。未建立病灶或個體血供分區模型。

## 檔案

- `腦與視覺路徑3D.html`：使用者單檔離線版。
- `index.html`、`app.js`、`style.css`、`assets/brain-packed.js`：可拆開維護的版本，同樣支援 file://。
- `assets/brain.glb`：244 個原來源網格子集，米為單位，約 20.6 MB，可另開至 Blender；不含補充示意曲線與 HTML 標籤。
- `完整構造清單.md`、`assets/landmarks.json`：70 項中英名稱、講義頁碼、分類及座標。
- `PDF原文.md`：影像型 PDF 的人工逐頁索引；不是 OCR 逐字稿。
- `assets/原始講義.pdf`、`assets/page-01.png` 至 `page-13.png`：原始資料與頁面轉圖。
- `assets/provenance.json`、`assets/model-source.json`：模型來源、轉換與 SHA-256。
- `assets/verification.json`：實際瀏覽器驗證結果。

## 修改與重建

需要 Node.js；目前依賴已安裝在本資料夾。名稱與說明改 `src/labels.js`，補充幾何改 `src/schematic.js`，互動改 `src/app.js`。

```powershell
npm run build
npm run assets
npm test
```

`src/export_brain.py` 只有重新擷取原模型時才需要 Blender。它目前讀取上一個專案的 `E:/NEWTEST/skull-atlas-3d/assets/Startup.blend`；一般使用與 HTML 重建不依賴那個資料夾。若要移機重做原始擷取，可從來源 GitHub 取得原始模型，再調整此路徑。建置只用本資料夾 `assets/brain-data.js`。

驗證：Chrome 離線開啟單檔；70 項模型／導引匹配、六主題、隱藏／恢復、跨主題搜尋、透明度／半腦／示意切換、滑鼠旋轉縮放、中英顯示、13 張嵌入圖解碼均通過。1440px 與 390px 六主題無標籤重疊或水平溢出；無 JS pageerror 或 HTTP 請求。這些是功能和顯示測試，並不等同醫學專業逐點審核。

2026-09-27 操作修正：改用 TrackballControls，每次預設視角重新建立控制基準，無慣性滑動；視窗尺寸變更同步更新控制範圍。`src/verify-interaction.cjs` 已驗證六個攝影機視角均可拖曳、停止後無漂移、標籤不跳位、懸停指線高亮。結果見 `assets/interaction-verification.json`。

## 完整 PDF

模型下方的「視覺路徑 PDF」會在新分頁開啟 assets/原始講義.pdf，可用瀏覽器的 PDF 閱讀器翻頁與縮放。PDF 在點擊時才載入；隱藏名稱時此入口也會隱藏。若搬移單檔 HTML 並需要此 PDF 入口，請一併保留 assets/原始講義.pdf 的相對路徑。PDF 仍依原權利人的授權使用。
