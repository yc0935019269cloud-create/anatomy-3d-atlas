# 腦神經與顱骨孔洞 3D 整合圖譜

直接用 Chrome 或 Edge 開啟 **神經與顱骨3D.html**（約 17 MB 單檔，離線可用）。頭骨、12 對腦神經與分支、眼窩內容物、海綿竇、蝶竇、硬腦膜與大腦放在同一個座標系裡，可以同時看到神經跟骨頭，也就是看得到每條神經穿過哪個孔。

## 八個主題

| 主題 | 內容 |
|---|---|
| 小考 10 題 | 視乳突、硬腦膜、Meyer’s loop、鋸齒緣、Gennari 線、距狀溝、視交叉、鼻淚管、上頷竇、蝶竇 |
| 顱底孔洞 | 移除顱蓋與腦，從上方看篩板、視神經管、眶上裂、圓孔、卵圓孔、棘孔、內耳道、頸靜脈孔、舌下神經管與穿過的神經 |
| 12 對腦神經 | 從腦底認每對腦神經的發出位置；點神經可跳到它穿的孔 |
| 眼窩與共同腱環 | 掀開眼窩頂，看眼外肌、共同腱環、III 上下支、IV、VI、額／淚／鼻睫神經、上眼靜脈、淚腺 |
| 眼部血管 | 眼動脈各分支、視網膜中央動脈（含視網膜上分支）與中央靜脈、睫狀後短（Zinn-Haller 環）、睫狀後長、睫狀前動脈 7 條、虹膜大／小動脈環、淚腺／眶上／滑車上／篩動脈、鼻背與眼瞼動脈、渦靜脈、上／下眼靜脈 |
| 海綿竇與蝶鞍 | 冠狀切面：外側壁 III→IV→V1→V2，腔內 ICA＋VI；腦下垂體、蝶鞍、蝶竇、經蝶竇路徑 |
| 睫狀神經節與瞳孔反射 | 三種根、長短睫狀神經、EW 核、III／IV 核、上丘、下丘、頂蓋前區 |
| 視覺路徑與皮質 | 視神經四段、視交叉、視束、LGN、Meyer／Baum loop、V1、楔葉、舌回 |

## 操作

- 拖曳旋轉（手感與頭顱骨圖譜相同：放開後輕微滑行再停住）、滾輪縮放、右鍵平移、雙指縮放。
- 「顱骨」調骨頭透明度。「切面」面板有水平（上下）、冠狀（前後）、矢狀（左右）三個切面，可同時開啟；各自有位置滑桿、「保留哪一側」切換，以及要切到哪些：骨頭、腦與腦膜、神經、其他（眼球、眼外肌、血管、鼻竇），四項可任意組合，沒勾的保持完整。被切掉的構造，指引線會自動隱藏。
- 神經依腦神經編號上色（畫面上方有色票）。
- 點神經 → 說明欄出現「穿過：○○孔」；點孔 → 列出「通過：」的神經，可互相跳轉。
- 選取一對腦神經（或一個孔）時，該神經左右兩條發亮，其他神經淡化；「其他神經」滑桿調淡化程度，拉到 0 就完全隱藏。其他構造的指引線會暫時隱藏，游標移到標籤上會暫時顯示。
- 「🔍 放大到這裡」把選取的構造移到畫面中央並放大。
- 「隱藏所有名稱」同步遮住標籤、側欄、流程文字、說明與重點整理，只留編號自測。
- 「重點整理＋小考答案」：孔洞表、眶上裂腱環內外、眼外肌、海綿竇、睫狀神經節、瞳孔反射、視神經、視覺路徑、水晶體與白內障、鼻竇與腦下垂體、腦幹，每項都有按鈕跳到模型。搜尋框輸入「小考 3」可找第 3 題。

## 模型與標示的可信範圍

全部網格由 Z-Anatomy 同一個 `Startup.blend` 擷取（410 個網格、714,982 個頂點；只有視網膜中央動脈因控制點極多而降低曲線取樣，其餘未簡化），所以骨與神經本來就對齊。驗證時量到的神經與孔距離：V2—圓孔 0.6 mm、CN II—視神經管 0.6 mm、V3—卵圓孔 1.4 mm、中腦膜動脈—棘孔 3.1 mm、XII—舌下神經管 4.1 mm。

- **原模型構造**（實線）：原作者已有的獨立網格。
- **原模型上的位置／通道**（實線）：孔洞、神經的某一段、上頷骨內的空腔。視神經管、圓孔、卵圓孔、棘孔、舌下神經管、枕骨大孔、蝶鞍取自原模型的標記線端點；眶上裂、頸靜脈孔、內耳道取自穿過它的神經在骨處交會的位置；篩板、頸動脈管為近似位置。
- **示意**（虛線）：原模型沒有的淚神經、鼻睫神經、睫狀神經節與三根、長短睫狀神經、頂蓋前區、視放射、睫狀肌、瞳孔括約肌、鋸齒緣環（沿原模型視網膜前緣畫）、經蝶竇路徑、上頷竇空腔提示、視神經的硬腦膜鞘（從視神經管到視乳突後方與鞏膜相連），以及原模型缺少的眼部血管（`src/ocular.js`：睫狀前動脈、虹膜大小動脈環、Zinn-Haller 環、視網膜中央靜脈、渦靜脈、眼瞼動脈弓、鼻背動脈、睫狀後長動脈的眼內走向、睫狀後短動脈接到鞏膜的細支）。原模型的視網膜中央動脈走在視神經下方、到視盤才接上，實際在眼球後約 1 cm 穿入視神經，說明以後者為準。
- **皮質內層次**（虛線）：Gennari 線在 V1 第 IV 層，沒有表面網格。

**共同腱環教學校正**：原模型的腱環開口只有約 5 mm，IV、額神經（V1 主幹）、上眼靜脈穿過環壁，看起來像在環內，VI 也卡在環壁。網頁載入時（`src/annulus.js`）把腱環在其平面上放大 1.5 倍，並只在腱環前後約 12 mm 內平滑移動這些構造：IV、額神經、上眼靜脈移到環外上方，VI 移進環內；原始資料檔未修改。驗證會量每條構造穿過腱環平面的位置。眼窩主題的「眶尖正面」按鈕沿眶軸、以平行腱環的切面直接觀看。

海綿竇切面中，本模型的 IV 與 V1 幾乎同高，ICA 在切面處略低於海綿竇；教科書排列以說明文字為準。這些都不是個人影像或專業逐點量測。成對構造主要標示左側。

## 檔案

- `神經與顱骨3D.html`：單檔離線版（資料、程式、樣式全部內嵌）。
- `index.html`、`app.js`、`style.css`、`assets/cranial-packed.js`：分檔版，需一起保留。
- `src/labels.js`：92 個學習項目與 7 個主題；`src/schematic.js`：示意幾何；`src/notes.js`：重點整理；`src/app.js`：互動。
- `src/export_combined.py`：從 Blender 原始檔重新擷取網格。
- `assets/model-inventory.json`、`assets/source-anchors.json`、`assets/landmarks.json`、`完整構造清單.md`：網格清單、原模型標記點、標籤座標、完整清單。
- `assets/provenance.json`：來源網址、SHA-256、座標系與改作。
- `assets/verification.json`：瀏覽器驗證結果。

## 重建

```bash
npm install
node build.mjs          # 由 assets/cranial-packed.js 建出兩個版本
node src/verify.cjs     # 離線瀏覽器驗證，更新 assets/verification.json
```

只有要重新擷取網格時才需要 Blender：下載 Z-Anatomy.zip（SHA-256 見 provenance.json），再用 Blender 或 `pip install bpy==4.2.0`（Python 3.11）執行
`python src/export_combined.py <Startup.blend> .`，會產生 `assets/cranial-data.js`（約 31 MB，不進版本控制），之後 `node build.mjs` 會重新壓縮成 `cranial-packed.js`。
